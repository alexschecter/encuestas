# Encuestas de colaboración

Encuestas de colaboración interfuncional. Las respuestas se envían a los Google Forms originales.

Para editar preguntas: `index.html`, sección "Contenido". Si cambiás preguntas, actualizá también la lista de `entries` en "Envío de respuestas".

Cada encuesta tiene su propio enlace: `#colaboracion`, `#colaboracion-cultura`, `#colaboracion-direccion`, `#colaboracion-cultura-direccion`.

Por cliente: `#<cliente>/colaboracion` (por ejemplo `#acme/colaboracion-direccion`). El cliente se guarda en el campo "Cliente" del formulario y el tablero filtra por cliente.
