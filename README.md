# Encuestas de colaboración

Encuestas de colaboración interfuncional. Las respuestas se envían a los Google Forms originales.

Para editar preguntas: `index.html`, sección "Contenido". Si cambiás preguntas, actualizá también la lista de `entries` en "Envío de respuestas".

Cada encuesta tiene su propio enlace: `#colab`, `#colab-cultura`, `#colab-direccion`, `#colab-cultura-direccion`.
